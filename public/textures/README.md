# Horizon texture

`black-marble-2016.jpg` is NASA Earth Observatory's Black Marble 2016 global
composite (VIIRS Day/Night Band, 0.1° equirectangular, 3600×1800), downloaded from
https://eoimages.gsfc.nasa.gov/images/imagerecords/144000/144898/BlackMarble_2016_01deg.jpg

NASA imagery is not copyrighted: https://earthobservatory.nasa.gov/image-use-policy
